Database Fundamentals — Study Notes

A relational database stores information in tables. Each table consists of rows and columns. A row represents a single record, while a column represents an attribute of that record.

A primary key uniquely identifies each row in a table. A primary key cannot contain NULL values. A foreign key links a column in one table to a primary or unique key in another table, helping enforce referential integrity.

SQL stands for Structured Query Language. The SELECT statement retrieves data from a database. The WHERE clause filters rows according to a condition. The ORDER BY clause sorts the results of a query. GROUP BY collects rows into groups, often used with aggregate functions such as COUNT, SUM, and AVG.

A database index is an additional data structure that can speed up reads by reducing the number of rows that must be scanned. Indexes require storage and add maintenance overhead to inserts, updates, and deletes. A B-tree index keeps its keys sorted and supports equality lookups and range queries.

A transaction is a group of database operations treated as a single unit. ACID stands for Atomicity, Consistency, Isolation, and Durability. Atomicity means that all operations in a transaction succeed or none take effect. Consistency means that transactions preserve defined database constraints. Isolation controls how concurrent transactions interact. Durability means that committed changes survive failures under the database's configured persistence guarantees.

Normalization organizes database tables to reduce redundancy and undesirable update anomalies. First normal form requires atomic values and no repeating groups. Second normal form removes partial dependencies on a composite candidate key. Third normal form removes transitive dependencies of non-key attributes on candidate keys.

An INNER JOIN returns rows with matching values in both tables. A LEFT JOIN returns all rows from the left table and matching rows from the right table, with NULLs where no match exists. A CROSS JOIN returns every combination of rows from the two tables.

PostgreSQL is an open-source relational database system. It supports transactions, foreign keys, indexes, and JSON data. Prepared statements separate query structure from parameter values, helping prevent SQL injection when used correctly.
